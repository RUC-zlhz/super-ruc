# SRS Diagram Assets

本目录保存 SRS 文档当前受版本控制的正式图源。

## 当前约定

- `mermaid/`：Mermaid 原始图源，是当前 SRS 图的正式文本源文件目录。
- `rendered/`：`v1.2 ~ v1.4` 历史主链仍直接依赖的受控 PNG 资产目录。
- `tmp/docs/`：仅作为渲染、导出、预览和临时实验目录，不再作为唯一正式图源入口。

## 使用规则

1. 修改 SRS 正式图时，优先修改 `mermaid/` 下的源文件。
2. 渲染得到的 `png / svg / emf / pdf` 默认属于中间产物，不直接放回本目录；例外是 `rendered/` 中为 `v1.2 ~ v1.4` 历史主链冻结保留的受控 PNG 输入资产。
3. 如某张图不再适合用 Mermaid 表达，应先在细化文件中记录替代方案，再决定新的正式源文件格式与目录。
