# Historical Rendered Diagram Assets

本目录保存 `v1.2 ~ v1.4` 历史 SRS 主链仍直接依赖的受控 PNG 资产。

## 子目录约定

- `v1_2/`：`v1.2` 模板生成链使用的冻结 PNG 输入。
- `v1_3/`：`v1.3` 从 `v1.2` 派生时使用的冻结 PNG 输入。
- `v1_4/`：`v1.4` 增量更新脚本使用的冻结 PNG 输入。

## 边界

- 这些 PNG 是“历史可复现输入资产”，不是新的正式图源格式。
- 新版本图的正式源仍应优先落在 `docs/source/diagrams/mermaid/`。
- `tmp/docs/diagrams/**/raw`、预览截图、比对图和测试图不进入本目录。
