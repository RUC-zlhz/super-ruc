## 模块一：智能问答与政策知识库

**功能概述**：提供基于官方权威文件的政策咨询、智能问答以及标准常用模板的下载服务。

### 面向学生（小程序端）

1. **政策咨询与问答**：进入小程序“知识库/问答”模块，在搜索框输入关键词（如“奖学金”、“休学”、“宿舍调整”）。系统将基于已发布知识条目返回摘要、命中原因和来源。
2. **查看官方文件**：在问答结果下方，可点击“查看原文件”直接浏览官方出具的通知或政策原文，确保获取的信息权威、准确无误。
3. **模板下载**：在“常用模板”专区，选择需要的模板（如《党员证明模板》、《团员证明模板》、《教室借用审批表》、《“求是学术”品牌研究项目立项申报书》），点击“下载”。系统将自动生成安全的下载链接，支持在手机端直接预览或复制链接至电脑端下载使用。

### 面向老师/管理员（Web 管理端）

1. **知识条目维护**：登录 Web 管理端，进入“知识库管理”。点击“新增条目”，录入政策标题、标准答复及办理流程，并可挂载官方附件（如 PDF 或 Word 原件）。
2. **模板上下架管理**：进入“模板管理”，上传最新的业务模板，配置适用场景和标签。若政策发生更新，可一键停用旧模板并上传新版本，小程序端将实时同步更新，避免学生使用过期文件。

## 模块二：党团事务流程管理

**功能概述**：实现入党、入团等长周期线性流程的可视化跟踪、关键节点自动提醒及理论自测。

### 面向学生（小程序端）

1. **进度追踪**：进入“党团中心” -> “我的流程”，页面将以时间轴（线性流程）形式直观展示你的党团全流程（如：入党申请人 → 积极分子 → 发展对象 → 预备党员 → 正式党员）。
2. **关键节点待办**：在流程详情中，当前所处阶段会被高亮显示；若该节点需要学生提交材料或说明，页面会明确列出“下一步需要完成”的动作（例如：按支部要求提交思想汇报）。若该节点由老师或支部处理，页面会提示等待进度更新。
3. **理论自测**：点击流程下方的“理论自测”入口，可参与党建知识答题，系统会自动判分并留存成绩作为辅助学习记录。

### 面向老师/管理员（Web 管理端）

1. **发起与节点推进**：进入“党团流程管理”，可通过学号或姓名精准搜索学生，为其绑定对应的党团模板并“发起流程”。若当前节点需要学生提交材料，老师可在列表中查看学生提交内容并点击“确认完成”；若当前节点无需学生提交，老师可直接确认该节点完成，系统将自动推进至下一阶段。
2. **提醒管理**：系统每天会自动运行提醒引擎。老师也可在“提醒管理”面板查看已发送的提醒记录，或对特殊情况的节点进行手动干预（如标记为“需人工跟进”或“已延期”）。

## 模块三：信息集成与精准推送

**功能概述**：实现学院各项通知的集中管理、标签化受众圈选以及多渠道的精准送达。

### 面向学生（小程序端）

1. **消息接收**：进入小程序“消息中心”，可集中查看所有推送到你账号的校内通知、就业信息等。
2. **通知触达**：高优先级或与你息息相关的重要通知（如“计算机类实习”），可通过小程序站内消息送达，便于集中查看。

### 面向老师/管理员（Web 管理端）

1. **信息聚类与录入**：进入“通知管理”工作台，新建通知内容（支持录入外部公众号文章链接或直接编辑富文本）。
2. **标签化精准分发**：在发送设置中，利用“画像标签”精确圈选目标人群（如指定“2024级”、“理科试验班”、“非毕业生”）。系统将自动计算命中人数，并支持通过站内信下发通知。

## 模块四：电子证明生成与审批流程

**功能概述**：提供各项证明的在线申请、审批通过后的 PDF 自动生成预览以及全链路的无纸化电子审批。

### 面向学生（小程序端）

1. **发起申请**：进入“办事大厅”，选择需要的业务类型（如：在读证明、请假申请、盖章申请）。
2. **证明提交与预览**：填写必要的用途说明并按业务要求上传佐证附件，确认无误后点击提交。申请审批通过后，系统会自动提取你的底层学籍信息（如姓名、学号、身份证号、入党时间等）并填充至标准版式，生成可在申请详情中预览的 PDF 证明。
3. **状态追踪**：在“我的申请”列表中，可实时查看每一笔业务的审批流转状态（待受理 → 审核中 → 已通过 / 已驳回 / 转线下处理）。

### 面向老师/管理员（Web 管理端）

1. **审批工作台**：进入“申请审核工作台”，列表会清晰展示所有待处理的事务申请。
2. **在线审核**：点击进入单笔申请单，左侧区域展示学生填写的表单信息与佐证附件，右侧为审批操作区。老师可直接填写审批意见并点击“审核通过”、“驳回”或标注为“转线下处理”。审批结果与意见将自动通过审计日志留痕并同步至学生端。

## 模块五：学业情况分析与预警

**功能概述**：基于权威成绩单解析与培养方案比对，为学生提供学业缺口预警；在管理员维护当前学期开课数据后，可进一步提供课程建议。

### 面向学生（小程序端）

1. **成绩单解析上传**：进入“学业分析”模块，点击“上传成绩单 PDF”。系统内置引擎会自动解析原件文本，提取你的成绩记录并提交至后台核验。
2. **缺口展示与选课建议**：成绩核验入库后，系统会将你的成绩与所属专业的培养方案进行自动比对。页面会高亮提示未修满的学分模块（学业缺口预警）。课程建议只基于已维护的当前学期开课数据生成；若尚未导入开课数据，页面将显示空建议或提示，不会用培养方案课程冒充实际开课。_（注：该界面会明确提示结果仅为学业参考，不代表最终毕业审核结论）_

### 面向老师/管理员（Web 管理端）

1. **成绩单核验入库**：进入“导入与核验中心”，系统会列出所有由学生上传解析产生的“疑似课程记录”。老师进行人工比对复核，确认解析无误后点击“提交入库”，成绩数据方可正式生效，确保数据严谨性。
2. **培养方案规则维护**：进入“学业规则管理”，管理员可灵活录入或调整各年级、专业的培养方案要求、学分模块划分以及课程等价替换规则，确保系统比对基准的准确性。
