## 候选 bug 记录规则

- 编号建议使用 `BUG-G7-001`、`BUG-G7-002` 递增。
- 崩溃类 bug 证据优先包含：截图或录屏、浏览器 Console、Network 状态码/响应体/耗时、刷新后是否恢复。
- Logic bug 证据优先包含：文档摘录、测试输入、实际输出、期望输出、页面截图或接口返回。
- 如果问题只在某个特定账号、浏览器或网络下出现，需要写清环境，避免被判为不可复现。
- 若第 7 组文档写明某限制且程序行为与限制一致，不应提交为 bug。
