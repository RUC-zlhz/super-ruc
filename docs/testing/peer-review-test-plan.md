## Bug 判定口径

| 类型 | 判定标准 | 基础分 | 典型场景 |
| --- | --- | ---: | --- |
| 崩溃类 bug | 程序无法启动、运行中崩溃、异常退出、无响应、服务中断、未捕获异常 | 15 分 | 页面白屏、后端服务崩溃、命令卡死无响应、文档缺失导致无法启动 |
| Logic bug | 程序可运行，但输出结果、功能行为或业务逻辑与预期不一致 | 8 分 | 计算错误、查询错误、排序错误、匹配错误、边界输入处理错误、文档描述与行为不一致 |

同一根因不得重复拆分为多个 bug；不得通过互相刷分、刻意重复提交等方式获取成绩。

## 报告质量要求

| 评价项 | 分值 | 执行要求 |
| --- | ---: | --- |
| 问题描述清楚 | 3 分 | 能清楚说明问题是什么、发生在哪个功能 |
| 复现步骤完整 | 4 分 | 他人能按步骤稳定复现 |
| 输入与输出明确 | 3 分 | 包含测试输入、实际输出、期望输出 |
| 证据充分 | 3 分 | 提供截图、日志、命令行输出、录屏或接口返回 |
| 修复建议合理 | 2 分 | 给出初步修改方向或可能原因 |

提交规范另计 `5` 分：按时提交 `2` 分，按模板填写 `2` 分，内容完整且无明显敷衍 `1` 分。
