1. 登记后打开第 16 组项目文档。
2. 若平台有使用说明文档，下载并记录文件名、下载时间和核心入口。
3. 当前公开接口显示 `has_usage_doc = true`、`has_basic_doc = false`；若平台页面确实缺少基本功能文档，先记为“文档风险”。
