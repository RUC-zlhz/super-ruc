- 数据库：Kingbase，库名 `student_platform`

## 运行说明

1. 解压 `UI -5.28.zip`。
2. 使用微信开发者工具导入解压后的 `UI` 目录。
3. 在开发者工具本地设置中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
4. 编译运行后进入“系统登录”页面。
5. 若接口失败，先检查 `http://10.10.0.17:8081/api/health` 和 `http://10.10.0.17:8081/api/test/db`。
