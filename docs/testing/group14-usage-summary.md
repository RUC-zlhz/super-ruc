## 小程序端功能范围

| 模块 | 文档描述的功能 |
| --- | --- |
| 登录与退出 | 输入账号密码登录，登录成功进入服务大厅，在个人中心安全退出 |
| 服务大厅 | 展示智能问答、党团事务、信息推送、电子证明、学业分析入口，并通过底部导航进入个人中心 |
| 智能问答政策库 | 输入问题并查看系统回答，支持奖学金、校园政策、事务流程等问题咨询 |
| 党团事务流程追踪 | 查看当前党团阶段、流程时间线、阶段顺序、状态和说明，区分已完成、进行中、未开始 |
| 信息推送精准集成 | 查看通知列表、标题、正文、发布时间、紧急标识，下载或预览附件，确认已读 |
| 电子证明生成与审批 | 选择证明类型、填写补充说明、提交申请，生成党员证明/团员证明 Word 预览，查看记录和状态 |
| 学业情况分析与预警 | 上传成绩单 PDF，解析已修课程、学分、缺失课程、建议和预警等级，并同步到个人中心 |
| 个人中心 | 查看姓名、学号、专业、总学分、已修课程明细，并退出登录 |
| 班团骨干功能 | 使用班团骨干账号登录，访问学生基础功能，查看与角色相关的班级或党团信息，并与普通学生权限区分 |

## Web 管理端功能范围

| 模块 | 文档描述的功能 |
| --- | --- |
| 后台登录 | 管理老师和系统管理员登录，根据角色进入对应管理页面 |
| 学生信息管理 | 查看、新增、编辑学生信息，维护学号、姓名、专业、年级、班级、联系方式、党团阶段等字段 |
| 通知管理 | 新建、编辑、发布通知，设置标题、正文、附件和目标对象，查看学生端接收与已读回执 |
| 电子证明与申请审批 | 查看学生证明或请假类申请、查看详情、审批申请、维护状态和流水记录 |
| 培养方案管理 | 上传培养方案图片，维护课程信息、课程数量、总学分和课程结构 |
| 党团流程数据管理 | 维护学生当前党团阶段和标准流程，支持小程序展示流程时间线 |
| 文件管理 | 存储通知附件、模板文件、成绩单、证明文件，支持下载、预览或业务调用 |
| 账号管理 | 系统管理员新增测试账户、修改账户、设置角色、维护状态、绑定学生学号 |

## 数据范围

- 用户账号：登录账号、角色、学生学号和账号状态。
- 学生信息：姓名、专业、年级、班级、联系方式、党团阶段。
- 文件数据：模板、通知附件、成绩单、证明文件。
- 培养方案：课程结构、课程数和总学分。
- 学业预警记录：成绩单解析、缺失课程、挂科课程和建议。
- 党团流程阶段：党团流程标准阶段。
- 证明申请：电子证明申请流水与审批状态。
- 通知与回执：通知内容、目标对象和学生已读状态。
