# 第 16 组崩溃类 Bug 专项排查清单

- 被测方：`第16组`
- 当前有效提交：`BUG-G16-002` 请假结束日期早于开始日期仍可提交成功（Logic bug，已提交）
- 本清单目标：继续寻找“崩溃类 bug”，即白屏、卡死、无响应、异常退出、服务中断、无法启动等问题。

## 判定边界

| 现象 | 是否崩溃类 | 说明 |
| --- | --- | --- |
| 小程序无法编译或无法进入登录页 | 是 | 按说明导入后仍无法启动，可记录启动崩溃 |
| 点击某页面后白屏、页面不可恢复 | 是 | 需截图页面和 Console 报错 |
| 操作后后端接口 500，且页面无可恢复提示 | 通常是 | 需记录 Network 响应和页面表现 |
| 页面一直 loading，无超时提示或无法继续操作 | 是 | 需录屏体现无响应持续时间 |
| 外部 AI 服务不可达但页面有明确错误提示 | 通常不是 | 更适合作为依赖异常或提示体验问题 |
| 表单规则错误但页面可继续操作 | 不是 | 归为 Logic bug |

## 取证设置

1. 微信开发者工具导入 `tmp/group16-docs/ui-src/UI`。
2. 勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
3. 打开调试器 `Console`、`Network`、`Storage`。
4. 每次测一个场景前清空 `Console` 与 `Network`。
5. 崩溃类证据至少包含：页面截图/录屏、Console 报错、Network 失败请求、复现步骤。
