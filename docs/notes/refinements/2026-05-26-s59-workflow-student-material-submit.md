# S59 党团流程学生提交材料与老师确认推进闭环

- 状态：`[x]` 已完成
- 日期：`2026-05-26`
- 目标：补齐党团流程中“需要学生材料的当前节点提交”和老师侧“确认完成后推进下一节点”的最小闭环，避免流程只能展示、不能由学生参与，同时避免把组织侧节点误开放给学生提交。

## 问题

- 生产中张念昊的入党流程已经发起，当前节点为“教育引导”。
- 旧实现中学生端只能查看当前节点、时间线和说明，不能提交材料或说明。
- 但官方 29 步中并非每个节点都需要学生交材料；如“教育引导”“党委审批”“公示”“存档”等属于老师、党支部或党委侧处理节点。
- 节点推进只存在后端老师接口 `/api/v1/admin/workflow/node-states/{state_id}/complete`，Web 管理端列表没有直接确认入口。

## 修复内容

- 后端新增学生侧接口：`POST /api/v1/workflow/node-states/{state_id}/submit`。
- 新增节点运行态 `MATERIAL_SUBMITTED`，语义为“学生已提交材料，等待老师确认”。
- 后端限制学生只能提交本人流程、当前节点、未完成节点，且该节点必须被判定为“需要学生提交材料”；不需要学生材料的节点返回 `40032` 并提示等待老师或支部处理。
- 后端在学生流程节点响应中新增 `student_material_required`，由后端统一告诉小程序是否展示提交入口。
- 官方默认模板补充真实学生动作节点的待办说明，例如“接收入党申请书并派人谈话”要求提交入党申请书，“考察”要求按支部要求提交思想汇报等培养考察材料，“递交转正申请书”要求提交转正申请书。
- 小程序流程详情页仅在 `student_material_required=true` 的当前节点展示材料提交区；组织侧当前节点显示“无需学生提交材料，请等待老师或支部处理”。
- Web 党团流程管理列表新增学生提交材料列，并提供“确认完成”按钮；材料列会区分“待学生提交”和“无需学生提交，老师可直接确认”。老师确认后沿用既有 `complete_node` 逻辑推进下一节点。
- `StatusTag` 补齐党团流程节点状态映射，`MATERIAL_SUBMITTED` 显示为“待老师确认”。
