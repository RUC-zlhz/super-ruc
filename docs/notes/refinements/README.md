# 细化文件规则

本目录用于保存“主计划之下的局部细化文件”。它们不是临时草稿，而是后续对话和实施必须持续更新的执行文件。

## 命名规则

- 推荐格式：`YYYY-MM-DD-<topic>-refinement.md`
- 示例：`2026-04-19-notice-loop-refinement.md`

## 必填内容

每个细化文件至少包含以下内容：

1. 标题
2. 日期
3. 关联主计划条目编号
4. 目标范围
5. 不在本次范围内的内容
6. 任务清单与状态标记
7. 验收条件
8. 风险 / 阻塞
9. 变更记录

## 状态图例

- `[ ]` 未开始
- `[-]` 进行中
- `[x]` 已完成
- `[!]` 阻塞

## 回写要求

1. 新建细化文件后，必须同步登记到 `docs/notes/current-implementation-plan.md`。
2. 每次相关工作完成后，必须同时更新细化文件与主计划文件。
3. 如细化方案被替代，不删除旧文件，只在文件头部标明“已替代”，并写出替代文件路径。
