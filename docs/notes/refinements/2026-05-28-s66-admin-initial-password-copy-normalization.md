# 2026-05-28 S66 管理端初始密码提醒文案去硬编码

- 关联主计划条目：`S66.1`, `S66.2`, `S66.3`
- 状态：`[x]` 已完成

## 背景

后台批量创建的新管理员账号会由系统生成一次性初始密码，并返回 `must_change_password=true`。现有 Web 登录页与个人信息页把改密提醒写死为 `admin123`，导致新管理员首次登录时看到错误提示，把默认 `admin/admin123` 超管场景和“系统生成初始密码”场景混在了一起。

## 范围

- 保留 `must_change_password` 的交互语义，不调整后端鉴权和改密接口。
- Web 登录页、个人信息页和改密弹窗去掉写死的 `admin123` 提示，统一改为“系统生成的初始密码/当前初始密码”类文案。
- 不改动默认超管种子 `admin/admin123`、开发冷启动脚本和互测说明中的共享账号口径。

## 执行拆分

- [x] `S66.1` 复核 `must_change_password` 触发路径，确认问题仅在 Web 提示文案硬编码。
- [x] `S66.2` 修改登录页与个人信息页提醒文案，去掉 `admin123` 的误导性提示。
- [x] `S66.3` 运行 Web 构建验证，并回写主计划与细化登记。

## 验证结果

- `.\web\node_modules\.bin\vue-tsc.CMD --noEmit -p web\tsconfig.json` 通过。
- `pnpm -C web build` 通过。

## 结论

本轮已将管理端“首次登录需改密”提醒从固定 `admin123` 改为通用初始密码文案，避免系统生成密码的新管理员看到错误提示，同时不影响默认超管账号的既有种子和运维口径。
