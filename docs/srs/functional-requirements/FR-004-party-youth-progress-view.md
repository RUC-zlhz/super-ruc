## FR-004: 党团进度查看

## Requirement

**ID:** FR-004  
**Title:** 党团进度查看  
**Priority:** Must Have  
**Status:** Draft

### Statement

The platform shall show each student the current stage, completed actions, and next required step of that student's party or youth workflow.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-003 | 学生需要平台提供本人党团流程中的当前阶段、已完成事项与下一节点信息 |
| Customer Problem | CP-003 | 党团流程节点缺少持续跟踪 |

## Acceptance Criteria

- [ ] 学生进入对应页面后可查看本人当前阶段名称。
- [ ] 页面展示已完成事项及其完成时间或状态。
- [ ] 页面展示下一节点所需动作或待办说明。

## Notes

- 仅展示该学生有权查看的本人流程信息。
