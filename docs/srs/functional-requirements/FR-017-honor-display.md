## FR-017: 奖励荣誉公示与榜样展示

## Requirement

**ID:** FR-017  
**Title:** 奖励荣誉公示与榜样展示  
**Priority:** Must Have  
**Status:** Draft

### Statement

系统应支持录入或导入经正式评定的校级及以上学生个人或集体荣誉记录（含国家奖学金、国家励志奖学金、校级优秀学生、学科竞赛国家级/省部级获奖等），并在学生端按类别与学年筛选展示榜单；展示内容需包含获奖者基本信息、授予单位、文号或证书编号、公示日期、事迹摘要；管理员可对过期、归档或撤销荣誉进行状态变更处理；学生本人未授权或未经学院审核的内容不得对外公开。

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-014 | 学生与学院需要平台集中公示校级及以上正式荣誉，树立榜样并支持授权合规 |
| Customer Problem | CP-011 | 荣誉信息分散于红头文件与线下通知，无法集中展示与查询 |

## Acceptance Criteria

- 管理员可批量导入或单条新增荣誉记录，并关联到学生学籍库进行身份核验。
- 学生端按"全部/类别/学年/级别"筛选后可查看生效状态下的荣誉卡片。
- 详情页展示获奖者基本信息、荣誉名称、授予单位、文号/证书编号、公示日期与事迹摘要。
- 历史/归档荣誉需明确标注"历史荣誉，仅供参考"，默认不主动推送。
- 对已毕业获奖者，个人联系方式等敏感字段不得展示。
- 任何新增/更新/归档/撤销动作均写入审计日志。

## Notes

- 仅校级（含）以上正式荣誉可进入展示：非官方评选、口头表扬、临时奖励不得收录。
- 榜样事迹需当事人授权（`consent_flag=True`）才能展示；未授权条目可入库但不公开。
- 批量导入复用 FR-009 文件交换模块的校验与原子提交机制。
