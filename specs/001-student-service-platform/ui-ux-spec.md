# UI/UX Specification

**Feature**: `specs/001-student-service-platform/spec.md`  
**Created**: 2026-04-13  
**Purpose**: 定义小程序端与 PC 管理后台的全局 UI/UX 规范，并补充核心页面的线框图级文本描述

## 1. 设计总原则

- **正式稳重**：界面风格优先体现学院事务系统的可信度、秩序感与规范性，不采用娱乐化或高噪音视觉表达。
- **高频任务优先**：学生端优先优化“查、提、看状态”，管理端优先优化“筛、审、导、查日志”。
- **一致性优先**：相同状态、操作和反馈文案在小程序端与 PC 端保持语义一致，避免多端规则割裂。
- **低认知负担**：学生端避免复杂菜单层级；管理端避免跨页完成同一关键任务。
- **边界可见**：凡涉及“仅学院预检 / 非正式生效 / 需人工核验 / 高敏字段受限”的场景，界面必须显式提示。

## 2. 全局 UI/UX 规范

### 2.1 色彩主题

#### 小程序端

- **主色**：学院红 / 深绛红  
  - 推荐：`#A61E2D`
- **主色深阶**：按钮按下态、标题强调  
  - 推荐：`#7F1722`
- **辅助色**：深蓝灰，用于导航标题、次级说明  
  - 推荐：`#334155`
- **背景色**：浅灰白，用于页面底色  
  - 推荐：`#F8FAFC`
- **卡片底色**：纯白  
  - 推荐：`#FFFFFF`
- **成功色**：`#15803D`
- **警告色**：`#D97706`
- **错误色**：`#DC2626`
- **中性边框色**：`#E2E8F0`

#### PC 管理后台

- **主色**：深红 + 深蓝灰组合，强调专业感与管理感
- **侧边导航底色**：`#1E293B`
- **顶部工具栏底色**：`#FFFFFF`
- **内容区底色**：`#F5F7FA`
- **主操作按钮**：`#A61E2D`
- **次操作按钮**：白底深灰边框
- **表格高亮行**：`#FFF7ED` 或极浅主题色

### 2.2 字体与排版

- **小程序端**
  - 标题：18-20px，半粗体
  - 正文：14-16px
  - 辅助说明：12-13px
  - 行高优先 1.5 倍，保证长文本可读
- **PC 端**
  - 一级页标题：24px
  - 模块标题：18px
  - 表格正文：13-14px
  - 表单标签：13-14px

### 2.3 图标与视觉元素

- 优先使用线性图标风格，避免卡通化图标。
- 学生端常用图标：搜索、进度、申请、通知、我的。
- 管理端常用图标：审批、导入导出、日志、统计、权限、知识库。
- 状态表达优先通过“文字 + 色块标签”组合，而不是只靠颜色。

### 2.4 导航结构

#### 小程序端导航结构

建议采用 **底部 4 栏导航 + 页面内快捷入口**：

1. **首页**
   - 今日通知
   - 常用事务快捷入口
   - 待办提醒
2. **服务**
   - 请假
   - 证明
   - 盖章
   - 模板下载
3. **进度**
   - 党团进度
   - 我的申请
   - 学业风险提示（若上线）
4. **我的**
   - 个人资料
   - 消息中心
   - 历史记录

**学生端设计原则**
- 底部导航栏数量不超过 4 个
- 首页承担“总览 + 快捷入口”，不承担复杂配置
- 事务列表和进度列表都要支持状态筛选

#### PC 管理后台导航结构

建议采用 **左侧主导航 + 顶部全局操作栏 + 内容区工作台**：

- **左侧导航一级菜单**
  1. 工作台
  2. 知识库管理
  3. 流程管理
  4. 审批中心
  5. 通知中心
  6. 导入导出
  7. 审计日志
  8. 统计报表
  9. 权限设置

- **顶部工具栏**
  - 全局搜索
  - 当前学期切换
  - 消息提醒
  - 当前登录人信息
  - 快速退出

**PC 端设计原则**
- 一级导航稳定，不因角色轻易移动位置
- 批量任务页面必须具备筛选、分页、导出和错误反馈
- 审批场景尽量在单一工作台内完成，不要求频繁切页

### 2.5 组件规范

- **按钮**
  - 主按钮：用于“提交、保存、通过、发布、导出”
  - 次按钮：用于“取消、返回、重置、预览”
  - 危险按钮：用于“停用、删除、强制回滚”
- **状态标签**
  - 待处理：灰蓝
  - 处理中：橙色
  - 已通过 / 已完成：绿色
  - 已驳回 / 失败：红色
  - 待人工核验：黄色
- **表单**
  - 必填项明确标识 `*`
  - 错误提示紧贴字段下方
  - 提交前提供摘要确认（尤其是导出和审批）
- **表格**
  - 支持固定表头
  - 支持列筛选和分页
  - 导出前显示当前筛选条件摘要

### 2.6 交互反馈规范

- **提交成功**：顶部轻提示 + 当前页状态更新
- **提交失败**：字段级错误 + 页面级错误摘要
- **导入失败**：必须给出批次号、失败记录数、可下载错误报告
- **审批成功**：状态标签即时变化，并记录“操作成功，已写入日志”
- **长耗时任务**：显示进度条或批次处理中状态，不允许静默等待
- **空状态**：给出明确说明与下一步操作入口

### 2.7 适配原则

- **小程序端**
  - 单页信息不宜过多，优先卡片化布局
  - 关键按钮放在底部固定操作区或明显区域
  - 搜索框、状态筛选和最近记录优先放在首屏
- **PC 端**
  - 工作台页面优先左右 / 上下分栏布局
  - 列表与详情并存时，优先使用“左表右详情”结构
  - 批量导出、导入日志和报表建议采用表格 + 侧栏详情模式

## 3. 核心界面线框图级文本描述

### 3.1 学生查看个人党团进度

#### 页面定位

- **端**：小程序端
- **页面名称**：个人党团进度
- **主要目标**：让学生快速看到自己当前阶段、已完成节点、下一动作和待办提醒
- **对应需求**：`CN-003`、`FR-004`、`FR-005`

#### 页面结构

**A. 顶部导航区**
- 返回按钮
- 页面标题：`我的党团进度`
- 右上角帮助按钮：点击后展示“阶段说明 / 咨询方式”

**B. 身份摘要卡片**
- 显示字段：
  - 姓名
  - 学号
  - 当前组织类型（如入党 / 入团）
  - 当前阶段
- 右侧状态标签：
  - `进行中`
  - `待补材料`
  - `待审核`
  - `已完成`

**C. 进度主时间轴**
- 纵向时间轴或分阶段卡片
- 每个节点显示：
  - 节点名称
  - 状态图标
  - 完成时间 / 预计时间
  - 节点说明
- 当前节点高亮显示
- 已完成节点显示绿色对勾
- 未开始节点显示灰色圆点

**D. 下一动作提醒卡**
- 标题：`下一步需要完成`
- 内容：
  - 下一节点名称
  - 截止时间
  - 所需材料
  - 注意事项
- 按钮：
  - `查看办理说明`
  - `联系老师`

**E. 历史记录折叠区**
- 可展开 / 折叠
- 展示字段：
  - 节点名称
  - 完成时间
  - 审核意见摘要

**F. 页面底部固定按钮区**
- 主按钮：`查看相关申请`
- 次按钮：`咨询人工`

#### 页面交互反馈

- 进入页面时先显示骨架屏，加载完成后渲染时间轴
- 若无有效流程记录：
  - 展示空状态插图 / 占位区
  - 文案：`当前暂无党团流程记录`
  - 按钮：`查看流程说明`
- 若当前节点已超期：
  - 在下一动作卡中显示红色提醒条
  - 文案：`当前节点已超过建议时间，请尽快联系负责老师`
- 若存在待补材料：
  - 顶部摘要卡显示黄色标签 `待补材料`
  - 历史记录区高亮最近一次驳回意见

### 3.2 辅导员批量导出考勤报表

#### 页面定位

- **端**：PC 管理后台
- **页面名称**：考勤报表导出
- **主要目标**：辅导员按班级、时间范围、课程 / 活动类型筛选考勤数据，并批量导出标准报表
- **说明**：该界面可视为管理端“导入导出 / 统计报表”能力在考勤场景下的典型页面
- **对应需求**：`CN-008`、`CN-011`、`CN-013`、`FR-009`、`FR-012`、`FR-013`、`FR-016`

#### 页面结构

**A. 顶部标题区**
- 页面标题：`考勤报表导出`
- 页面说明文字：`按筛选条件生成标准 Excel 报表，导出行为将写入审计日志`

**B. 筛选条件区**

第一行筛选项：
- 学期下拉框
- 年级下拉框
- 班级下拉框
- 报表类型下拉框（课程考勤 / 活动考勤 / 汇总报表）

第二行筛选项：
- 开始日期选择器
- 结束日期选择器
- 课程 / 活动名称输入框
- 状态下拉框（全部 / 迟到 / 缺勤 / 请假）

操作按钮：
- `查询`
- `重置`
- `保存本次筛选`

**C. 结果摘要区**
- 统计信息卡片 4 个：
  - 总记录数
  - 缺勤人数
  - 迟到人数
  - 请假人数

**D. 表格区**

表格栏位建议：
- 选择框
- 学号
- 姓名
- 年级
- 班级
- 课程 / 活动名称
- 日期
- 考勤状态
- 请假原因摘要
- 记录来源
- 最后更新时间

表格能力：
- 表头排序
- 分页
- 多选
- 固定表头

**E. 导出操作区**
- 主按钮：`导出当前筛选结果`
- 次按钮：`导出所选记录`
- 次按钮：`下载模板`
- 文字提示：
  - `仅导出当前权限范围内数据`
  - `高敏字段将按策略脱敏`

**F. 右侧批次详情抽屉 / 下方面板**
- 最近导出批次列表
- 显示字段：
  - 批次号
  - 导出时间
  - 导出人
  - 文件状态
  - 下载链接
  - 失败原因（若失败）

#### 页面交互反馈

- 点击 `查询` 后：
  - 表格进入加载态
  - 顶部显示当前筛选摘要
- 无结果时：
  - 表格区域显示空状态
  - 文案：`当前筛选条件下无可导出数据`
- 点击 `导出当前筛选结果` 后：
  - 弹出确认框
  - 确认框内容：
    - 导出范围
    - 预计记录数
    - 脱敏规则摘要
  - 按钮：`确认导出` / `取消`
- 导出成功后：
  - 页面右上角提示：`导出任务已创建`
  - 最近导出批次列表新增一条记录
- 导出失败后：
  - 提示框显示失败原因
  - 若是权限原因，提示：`当前账号无权导出该范围数据`
  - 若是批次异常，提示下载错误报告或联系管理员

## 4. 端侧差异总结

| 维度 | 小程序端 | PC 管理后台 |
|------|----------|-------------|
| 主要目标 | 快速查询、提交、查看状态 | 高效筛选、审批、导入导出、审计追踪 |
| 页面结构 | 单列卡片式、任务导向 | 表格 + 筛选 + 详情面板 |
| 导航方式 | 底部导航 + 页面内入口 | 左侧导航 + 顶部工具栏 |
| 操作风格 | 少步骤、少字段、强反馈 | 多筛选、强控制、批量操作 |
| 风险提示 | 边界文案前置 | 权限、导出、日志说明前置 |
